# openspec/changes

## Purpose

OpenSpec change-local artifacts and archived changes.

## Ownership

Active change directories hold proposal/specs/design/ADR/tasks artifacts; `archive/` holds completed change history. OpenSpec CLI owns lifecycle metadata.

## Local Contracts

- Follow selected schema gates and artifact paths.
- Do not create or edit change records outside OpenSpec workflow.
- Keep archived changes immutable unless OpenSpec explicitly supports migration.

## Work Guidance

Use `openspec status` and `openspec instructions` before editing any change.

## Verification

Run named change proof and strict OpenSpec validation before claiming completion.

## Child DOX Index

No child DOX files. Change names are dynamic lifecycle boundaries.
